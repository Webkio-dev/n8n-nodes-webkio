# Changelog

## 0.2.0

- Webkio node: create or update a contact, get contacts, add a subscriber (optionally to a list),
  get email lists, create a blog post draft, and get orders by number, email, status or site.

## 0.1.0

- Webkio Trigger: new order, order paid, new booking, new rental reservation, new subscriber, new
  property enquiry and new product review, with an optional site filter and signed deliveries.
- Webkio API credential (API key).
